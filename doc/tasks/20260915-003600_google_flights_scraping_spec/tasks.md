# タスク計画: Google Flights スクレイピング仕様の刷新と不整合修正

## 1. 概要・背景

Google Flights の自動巡回において、スクリーンショットとスクレイピングされた金額が一致しない重大な不整合（時刻文字列 `8:50 – 15:15` を誤認して `8,501,515円` とパースするバグ等）が発生していた。
ユーザーから提供された実画面 HTML サンプル (`doc/work/GoogleFlightサンプル/`) の DOM 解析結果に基づき、以下の要求仕様に準拠したスクレイピング仕様・ドメイン・UI への全面改訂を行う。

### 要求仕様
1. **1段階目の検索（基本検索条件）**:
   - 出発地 (Origin)
   - 目的地 (Destination)
   - 出発日 (Outbound Date)
   - 出発時間レンジ (Outbound Time Range: 例 任意/朝/昼/夜/指定時刻)
   - 到着日 (Inbound Date, 往復時)
   - 到着時間レンジ (Inbound Time Range)
2. **2段階目の検索（検索結果画面フィルター）**:
   - 経由地数 (Stops): `指定なし` (Any), `直行便` (DirectOnly), `1箇所まで` (Max1Stop)
3. **ソート順**:
   - `安い順` (Cheapest first)
4. **取得件数**:
   - `10件` (設定値として変更可能)
5. **整合性担保と画面キャプチャ**:
   - スクリーンショット撮影と価格データ（上位10件、最安値）の完全一致
   - キャプチャサイズは明示的なウィンドウサイズ（ViewportSize: 1440x900 等）として定義
6. **便名（Flight Number）の完全抽出と同一航空券認識**:
   - カード内 `itinerary=...` 属性から各区間の便名（例: `5J 5055`, `NH 869`, `PR 431`）を抽出
   - 同一航空券キー（`flight_key`: `task_id` + `flight_numbers` + `outbound_date`）を導入し、日々の同一便の価格推移を正確に追跡
