## 1. サブエージェント指摘事項サマリー

### 【ユーザーロール指摘】

- **Critical-U01: 前タスクで実装したモーダルナビゲーション・UX改善の退行（リグレッション）絶対防止**
  - 前回のタスク（`20260910-014500_fix_modal_close_navigation`）で解決した「モーダルが確実に閉じる」「ブラウザ戻るボタン連動（History API）」「ESCキー安全クローズ」「エラー時に入力データが消えないインライン表示」が、モックの静的HTML構造への回帰によって損なわれてはならない。
  - モックの見た目・レイアウト・入力項目を 100% 再現しつつ、背面のナビゲーション・ステートマシン（`openModalSync`, `closeCurrentModal`, `HX-Trigger: closeModal`）を確実に継承すること。
- **Major-U02: 新規登録・編集モーダルでの「往復」「片道」動的切り替えUXの完全担保**
  - モック通り「片道」選択時には復路出発日入力フィールドが滑らかに非表示（または無効化）となり、バリデーションも片道として通るようにすること。
- **Major-U03: 空港datalistサジェストとIATAコードパースの利便性**
  - ユーザーが「HND - 東京(羽田)」のような日本語つき候補を選択した場合でも、サーバー送信時に正しく「HND」として解釈される、あるいは柔軟にパースできる設計とし、入力エラーで弾かれないように配慮すること。
- **Major-U04: 削除確認モーダル (`#deleteModal`) の明確な対象表示と誤操作防止**
  - ネイティブ `confirm()` から `#deleteModal` へ移行する際、削除対象のルート名（例: 「東京(羽田) → パリ(CDG)」）がモーダル中央に明示され、キャンセルボタンが明確に機能すること。
- **Minor-U05: Excel風リストビューのフィルタ・ソート視認性とリセット操作**
  - ドロップダウンで絞り込んだ際、どのフィルタが効いているかをアクティブフィルタチップスバーで一目で把握でき、「全解除」ボタンで即座に初期状態へ戻せること。

### 【SE/PGロール指摘】

- **Critical-T01: HTMX 動的DOM更新における Lucide Icons の再描画ライフサイクル保証**
  - Lucide Icons は `<i data-lucide="..."></i>` を JS の `lucide.createIcons()` で SVG に変換する仕組みである。
  - HTMX の部分更新（`hx-swap`, OOB swap）やモーダル動的オープン（`/api/tasks/new-modal` 等）が発生した直後に `lucide.createIcons()` を呼び出さないと、挿入された要素のアイコンが空っぽ（非表示）になる。
  - グローバルな `htmx:afterSwap` および `htmx:afterOnLoad` イベントリスナーで常に `lucide.createIcons()` を自動実行する堅牢なライフサイクルフックを `layout.clj` に導入すること。
- **Critical-T02: ドメイン層・DTO層とモック入力フィールドの整合性**
  - 新規登録・編集モーダルで「旅行タイプ (往復/片道)」「許容乗継回数 (Any / 1 / DirectOnly)」「巡回間隔 (3 / 6 / 12 / 24)」「優先航空会社」「Discord Webhook 通知フラグ」が追加・変更される。
  - `api_controller.clj` のフォームパラメータ受け取りロジック、および `domain.clj` / `validation.clj` への受け渡しがこれらすべての項目と矛盾なく連動しているかを精査すること。
- **Major-T01: Excel風フィルタおよびソートのクライアントサイドJS統合**
  - モック内の `index.html` に記載されているフィルタ関数（`applyAllFilters`, `setStatusFilter`, `setRouteFilter`, `setAirlineFilter`, `toggleSort`）のロジックを整理し、`dashboard.clj` に安全に組み込むこと。
- **Major-T02: ソースコードとテストコードの 1:1 対応規約の厳守**
  - UIの文言・構造・アイコンタグ（`<i data-lucide="...">`）変更に伴い、既存の単体テスト（`layout_tests.clj`, `dashboard_tests.clj`, `modals_tests.clj`, `api_controller_tests.clj` 等）のアサーションを漏れなく更新し、テストが全件合格することを保証すること。
